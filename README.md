# Mycelium-Digital Twin System

A scalable, IoT-driven circular supply chain solution designed to monitor compostable mycelium packaging in real-time.

## Innovation
* **Material:** Compostable mycelium packaging.
* **Data:** Real-time structural monitoring to reduce shipping damage waste.
* **Sustainability:** Quantified carbon credits calculated per unit.

## Tech Stack
* **IoT Protocol:** MQTT for low-latency transmission.
* **Backend:** Python-based microservices.
* **Deployment:** Docker containerization.

## Project Structure
* `/backend`: Contains microservices for data processing and sustainability analytics.
* `/edge`: IoT simulation logic for sensor data collection (temperature and structural integrity).
